# 个人网站设计文档

## 概述

搭建一个个人导航网站，集中管理常用网站书签和 GitHub 项目链接。网站以「学校」「工作」「生活」三大分类组织内容，采用极简程序员风格和暗色主题。支持在网页上直接增删改查链接，数据持久化到浏览器本地存储。

## 技术方案

- **纯静态页面**：单个 `index.html`，CSS 和 JS 内嵌，零依赖
- **托管**：GitHub Pages（免费，自动 HTTPS）
- **数据持久化**：预置数据写在 JS 对象中，用户新增/修改的数据通过 `localStorage` 保存，页面加载时合并
- **无需构建工具**，浏览器直接打开即可使用

## 视觉设计

| 元素 | 规格 |
|------|------|
| 主题 | 暗色（背景 `#0d1117`，卡片 `#161b22`） |
| 正文颜色 | `#c9d1d9`（浅灰白） |
| 主色调 | 蓝色 `#58a6ff`，绿色 `#3fb950`（项目标签） |
| 字体 | 等宽字体优先（SF Mono / Fira Code），回退系统等宽 |
| 卡片 | 圆角 8px，边框 `#30363d`，悬浮高亮变蓝并微上浮 |
| 图标 | 🔗 外链、🐙 GitHub 项目、↗ 跳转箭头、✏️ 编辑、🗑️ 删除 |

## 页面结构

```
🏠 个人介绍区
   ├─ 名字（guozikang）
   └─ 一句话标签（开发者 · 终身学习者）

📑 标签页导航
   ├─ 🎓 学校
   ├─ 💼 工作
   └─ 🌈 生活

📇 内容区（每个标签页内结构一致）
   ├─ 🔗 外部链接
   │    └─ 卡片列表（图标 + 名称 + URL + ✏️🗑️ 操作按钮 + ↗）
   └─ 🐙 我的项目
        └─ 卡片列表（图标 + 名称 + GitHub 路径 + ✏️🗑️ 操作按钮 + GitHub标签）

➕ 右下角浮动添加按钮
   └─ 点击弹出添加表单（模态框）

   └─ © 2026 guozikang
```

### 卡片设计

每张卡片包含：
- 左侧：类型图标（🔗 或 🐙）
- 中间：链接名称（加粗）+ URL/路径（灰色小字）
- 右侧操作区：✏️ 编辑按钮、🗑️ 删除按钮（悬浮时显示）、外链显示 ↗ 或绿色 `GitHub` 标签
- 整张卡片可点击跳转（但点击 ✏️🗑️ 时不跳转）

### 浮动添加按钮

- 固定在页面右下角，圆形蓝色按钮，显示 `+` 或 `➕`
- 点击弹出模态表单
- 不受标签页切换影响，始终可见

### 添加/编辑表单（模态框）

弹出居中模态框，包含以下字段：
- **所属分类**：下拉选择 学校 / 工作 / 生活（添加时默认为当前打开的标签页）
- **类型**：下拉选择 外部链接 / 我的项目
- **名称**：文本输入框
- **URL**：文本输入框
- **保存** 按钮 / **取消** 按钮
- 编辑模式下，表单预填当前数据

## 数据模型

```javascript
// 预置数据（直接写在 JS 中）
const defaultData = {
  school: {
    links: [],
    projects: [],
  },
  work: {
    links: [],
    projects: [],
  },
  life: {
    links: [],
    projects: [],
  },
};

// 运行时数据结构（预置数据 + localStorage 合并）
// localStorage key: "siteData"
// 存储格式：与 defaultData 相同结构的 JSON

// 用户添加的每条链接记录：
// { id: "唯一ID", name: "名称", url: "https://...", addedByUser: true }
// addedByUser 标记用户新增的链接，用于区分预置数据
```

### 数据合并逻辑

1. 页面加载时，读取 `defaultData` 和 `localStorage.siteData`
2. 将 localStorage 中的用户数据按分类和类型合并到对应数组
3. 用户添加/编辑/删除操作同时更新内存数据和 localStorage
4. 空数组的分类自动隐藏对应子区域标题

## 交互逻辑

### 标签切换
- 点击顶部标签，切换显示对应分类内容，当前标签高亮蓝色

### 卡片交互
- **悬浮**：边框变蓝 + 轻微上浮阴影 + 显示 ✏️🗑️ 操作按钮
- **点击卡片**：新标签页打开链接
- **点击 ✏️**：弹出编辑表单，预填当前数据
- **点击 🗑️**：弹出确认提示，确认后删除

### 添加链接
1. 点击右下角 `+` 按钮
2. 弹出模态表单，分类默认选中当前标签页
3. 填写分类、类型、名称、URL
4. 点击保存，链接添加到对应分类和子区域
5. 数据写入 localStorage，即时刷新列表

### 空区域处理
- 某子区域无数据时，隐藏该区域标题
- 当前标签页下所有区域均为空时，显示提示文字"暂无内容，点击右下角 + 添加链接"

### 响应式
- 移动端：标签可横向滚动，卡片占满宽度，浮动按钮位置不变
- 模态框在小屏幕上占满宽度，保持可用

## 假设

- 使用 GitHub 默认的暗色配色体系（GitHub Dark 风格）作为视觉基础
- 用户数据持久化在浏览器 localStorage 中，不会跨设备同步
- 不校验 URL 格式，原样渲染，用户自行保证正确性
- 本地尚未上传的脚本项目暂不列出，等上传 GitHub 后再添加
- 暂不包含 favicon 和 Open Graph 标签，后续可补充
- 卡片点击跳转和编辑/删除按钮通过事件冒泡控制区分
